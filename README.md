# 라이프케어서비스 홈페이지

취급 상품과 상품별 납품·설치 사례(블로그 글)를 보여 주는 모바일 우선 정적 사이트입니다. 저장소를 Vercel에 연결하면 별도 설정 없이 배포됩니다.

## 구조

- `index.html` 화면 뼈대와 스타일
- `app.js` 데이터를 읽어 목록, 상품 상세(`/#상품id`), 사례 카드, 관련 소식을 그립니다
- `data/` 상품, 카테고리, 블로그 글, 기사, 사이트 정보 JSON
- `docs/ROADMAP.md` 기사 자동 수집, 관리자 페이지, 결제 설계

## 내용 수정

지금은 `data/*.json` 을 고치면 사이트에 반영됩니다. 블로그 글을 상품에 연결하려면 `posts.json` 의 `productIds` 에 상품 id를 넣으세요.

현재 상품, 가격, 사례 글, 기사는 예시입니다.
